# 建筑超写实渲染

把已有渲染图提升为真实建筑摄影观感。优先级：**用户明确的几何事实与源模型位置 → 原始主图的构图和结构 → 经核对的通道信息 → 跨视角材质台账 → 摄影风格**。增强真实感不能成为改变设计的理由。

## 先读图，再写提示词

1. 确定工作范围：仅分析/写提示词，还是已授权生成；明确主图名单、输出位置、材质及光照意图。沿用已有授权，只在缺失信息影响主体识别时提问。
2. 清点主图及其同名通道。可运行 `scripts/inventory_render_set.py`：它只做文件配对、尺寸和哈希检查，**不做视觉识别**。先处理重复配对、错尺寸、孤立通道，不能把这些文件混入其他机位。默认仅扫描指定目录，不把生成结果子目录重新当作输入。非“场景”命名的主图也需纳入用户指定范围。
3. 用可查看图像的工具实际读取每张主图和可用的同机位通道，按 [通道识别与跨视角对应](references/passes-and-consistency.md) 完成识别。不要只根据文件名或一张代表图为整批套词。大图需要时检查主体、岸线和连接处的局部细节。
4. 记录每张图的主体、视角、轮廓、分岔/孔洞、支承、遮挡、岸线与陆水分区。区别“能看清”“用户确认”“推断”“待确认”。对岸上桥墩、台阶落点等关键关系，用户明确说明优先于模糊图面。不能因画面底部颜色类似河水就整片替换成水面。
5. 多机位先建立同一物体的对应关系和材质台账，再分别写词。每个物理建筑/构件用稳定 ID；在各图中记录位置描述或归一化框，以及匹配证据与置信度。共享材质颜色不等于共享物体身份。匹配不确定时沿用保守表面处理，不凭空指定细致立面。

## 必须保持的约束

- 保留相机位置/高度、透视、裁切、画幅、桥梁和建筑位置、朝向、体量、轮廓、构件厚度、开口、支承数量、台阶、道路和场地连接。不得把俯瞰改平视，也不添加原图不可见的天空。
- 陆地、水体、岸墙、绿地和步道分别处理。保持岸线、水位和接触关系；陆上桥墩周围仍是陆地，不能淹没步道、把岸墙改桥墩或凭空造水中基础。清晰的反射也不能盖过真实构件边界。
- 区分实体栏板、金属、透明玻璃；白色实体不能因“高级感”变透明玻璃。保持原有分缝、窗格、开口与拓扑。不得增加原图没有的拉索、桥塔、拱肋、顶棚或建筑。
- 同一栋建筑、同一立面在不同视角中的材质族、底色、窗格/分缝布局、纹理方向与实际尺度应一致。透视压缩、光照明暗和玻璃反射可随视角自然改变；不能按每张图的屏幕方向重新贴图。
- 白模立面没有真实窗格依据时，先保持原体量并使用克制表面纹理。只有用户允许补全立面时，才在台账中定义一次统一的概念立面，所有对应视角复用；不能宣称这是现状立面。

## 按图编写提示词

读 [摄影与材质提示词模块](references/prompt-patterns.md)，只选当前画面适用的词，按以下顺序组织：

1. 本张原始主图是编辑目标；每张辅助图的角色与适用范围。
2. 本张几何与接触关系的具体锁定描述，尤其易被误识别的部分。
3. 可见物体 ID → 固定材质定义；明确哪些表面不修改。提交生成时把 ID 翻译成模型能识别的位置和外观描述，不能只给抽象 ID。
4. 针对本张的纹理、反射、水面、天空、光线和阴影处理。以实际尺度的粗糙度、接缝和微细变化营造真实感，不堆砌“8K、电影级、大师级”。不得把文字分辨率标签当实际输出尺寸。
5. 与其他视角共用的物体身份和材质，及本张禁止发生的变化。写清“不透明”比泛称“白色高级材质”更可靠。

保留已选定的镜头，不凭空指定 35mm/50mm、浅景深或重新构图。未知焦距只描述当前视角。光照应与原图和整套场景意图一致；从不同方向拍摄时，世界中的太阳方向一致，画面中的投影方向不必相同。

## 执行与检查

只要求 skill、分析或提示词时不生成。用户要求先确认提示词时先交付具体提示词；已有授权则按范围继续。

生成时遵循当前可用图像编辑工具的使用规范；在 Codex 内置图像工具可用时使用它，批次逐张调用。将通道作为多模态辅助图，不声称已启用工具未提供的深度控制、分割遮罩或 ControlNet。风格参考和结构参考角色分开：经核对的成图可以辅助统一质感，不能覆盖当前原图几何或传递上一张错误。

每张生成后与原始主图对照，再和其他视角对照同一建筑：检查轮廓、落点、陆水边界、开口/栏板透明性、立面布局、材质尺度、阴影和反射。出现关键位置或身份漂移时，不把“更好看”视为通过。可做一次针对性局部修正；同一关键问题仍存在就保留为未通过并说明，避免无界重抽。用户可授权进一步迭代。

纯生成式二维编辑不能保证像素级几何锁定或真正共享三维 UV。若任务要求严格一致，应说明当前结果的实际检查程度，优先采用用户允许的遮罩局部编辑或源场景统一材质后重渲；不擅自修改源模型，不把建议说成已经完成。

## 保存可复用记录

在项目输出目录按任务规模保存输入清单、几何约束、跨视角物体/材质台账、逐图提示词和检查结果；单张简单处理可合并为一个记录。保存实际生成尺寸，区分源图和成图，不覆盖原图。报告成图、提示词路径及关键未通过项。

用户的项目事实写在项目记录，不能固化成所有项目的默认设定。来源与研究依据见 [sources.md](references/sources.md)；需要更新工具能力或通道语义时再查官方资料。
