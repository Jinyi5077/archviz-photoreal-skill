# 摄影与材质提示词模块

以下为根据官方提示词与渲染资料整理的编辑模式，示例措辞为本技能编写。每张图需先识别，再实例化；不要完整复制所有模块。跨机位复用的是物体和材质定义，不是相同的屏幕位置或同一段泛化文字。

## 提示词结构

```text
任务：对指定原始渲染主图做超写实建筑摄影后期，只改变授权的表面、环境质感和光照。
输入角色：逐张说明编辑目标、Albedo、Normal、其他已验证通道，以及可选的材质外观参考；通道不作为颜色或艺术风格。
本图识别：说清主体的可见形态、相机视角、关键构件与其位置，区分水域、陆地和遮挡。
几何锁定：列出本图不能变的轮廓、结构、支承、开口、落点、岸线、道路、模型位置、镜头和裁切。
材质对应：对每个相关对象或表面写入固定材质，说明跨视角对应的外观参考及不可改变的窗格/分缝。
真实感：选择与可见表面、尺度相符的微纹理、粗糙度、反射、水纹、天空与阴影。
本图排除：只写与本图有关的高风险误改，包括实体变玻璃、岸上变水中、建筑体量或立面身份漂移。
输出：单张完成图，保持源画幅；尺寸要求以工具实际支持为准，无通道拼贴、文字或水印。
```

可选英文控制语句：

> Edit the supplied original render; preserve its camera, framing, object placement, silhouettes, openings and support contacts. Change only the specified surface appearance and lighting. Treat auxiliary passes as geometric or material-region evidence, never as the final color palette.

> Reuse the same object-specific facade and material definitions across views. Preserve window layout, joint spacing, texture scale and object-space orientation. Let reflections and shading respond naturally to each camera; do not invent a new facade for each image.

## 可选真实感词汇

| 目标 | 适用表达 | 常见误导 |
| --- | --- | --- |
| 浅白实体结构 | 略带暖灰的浅白色，哑光、细微粗糙度、尺度真实的微孔，克制分缝，保留高光细节 | 粗大孔洞、厚重污渍、发光纯白、把细构件变粗 |
| 白色涂装金属 | 细腻低光泽白色涂层，薄而清晰的边缘，细微反射，原有连接件 | 每条边都发亮、塑料感、覆盖原有连接关系 |
| 混凝土铺装/浅石材 | 防滑微粗糙表面，正确尺度的原有铺装分缝，细微自然色差 | 凭空重分割桥面、大块大理石花纹、强烈湿反光 |
| 暖铜色扶手 | 克制的暖铜色，细微金属反射和轻微拉丝，保持管径和曲线 | 镀金、高饱和橙色、金属颜色扩散到实体栏板 |
| 实体栏板 | 浅白不透明哑光实体板，仅原有窄缝透出背景 | 透明玻璃、半透明树影穿透、全反射镜面 |
| 既有建筑立面 | 按该建筑台账定义的石材/抹灰/混凝土和玻璃，保持窗格、层高节奏、转角连续性 | 全街区同一幕墙、不同机位随机砖石/玻璃互换 |
| 水面 | 保持既有水域范围，灰蓝绿低饱和水色，尺度适当的微风水纹，随波破碎的环境反射 | 把岸上铺装变水、热带透明蓝、海浪、镜面复制倒影 |
| 天空 | 在已存在天空区域中使用自然淡蓝、薄云或符合原天气的层次 | 俯瞰图新增地平线，日夜混杂，过度戏剧云 |
| 光影 | 与原图意图一致的自然日光，天空补光，柔和真实的半影与接触阴影，桥下仍有细节 | 同图多个太阳、阴影漂浮、黑缝、过曝白块、HDR 光晕 |
| 植被 | 保持位置及体量，叶片尺度自然、树冠疏密有层次，配合原季节 | 随意增加绿带、树木遮住主体、把初秋全变深橙 |

材质不是仅靠底色定义：写清物理表面、微粗糙度、纹理尺度、接缝和透明性。用环境光解释表面明暗，不把所有阴影和高光画进 Albedo。控制词以画面实际可辨细节为准，远景不要求表现肉眼不可见的微孔。

## 按视角调整

- **岸边低视角**：描述前景支承的原裁切、陆上接触范围、岸墙、水位；保留桥底遮阴和结构厚度。水面只在确认的水域增强。
- **桥面平视**：描述前景铺装与栏杆引导线、两条路径间空隙、顶棚或桥头位置。不添加遮挡关键连接的配景。
- **顶棚/节点近景**：保持原有近景裁切，强调材料微纹理、连接接触与合理暗部。不要要求同时展示完整全桥。
- **垂直俯瞰**：保持原有平面范围、道路和屋顶轮廓、桥梁相对尺度，不添加天空。纹理、水纹和人物服从航拍尺度。
- **斜俯瞰**：优先可读的主体轮廓、支承和两岸连接，周边立面根据对应关系赋材质；远处自然空气透视，不改变楼高。
- **逆光/暖下午**：保留原光照意图，用自然补光恢复结构，不把浅白主体变橙黄色，不强制所有机位都相同屏幕方向的侧光。

## 单图示例：已确认岸上支承的桥梁

以下是演示约束表达的方法，不是所有桥的固定材质或地形：

> 以本张原始桥梁渲染为唯一几何和构图基准，保持低视角、画面右侧前景桥墩的原有裁切、桥面曲线、拱肋和两片折板顶棚。右前景桥墩位于河岸铺装上，墩脚周围保持干燥陆地，保留岸墙与现有岸线；水纹和反射只出现在原有河道内，不能让河水包围桥墩。主体采用台账中选定的浅白色细腻哑光材质，保留构件厚度、白色不透明栏板和暖铜色扶手。左岸已对应的建筑复用其固定立面、窗格和材质定义，不改变体量或按本机位重新设计。晴朗下午的自然日光与天空补光，真实接触阴影，桥下有层次，浅白高光不溢出；只在原有天空范围完善薄云。无新增桥塔、拉索、建筑、树木或水域。

若只凭原图无法判断岸线，把确定部分先写好，局部保守保留；只有依赖该判断的操作才等待澄清。不要用“国际竞赛级”“超真实”掩盖关键识别缺失。

## 输出提示词前自检

每段材质描述能否对应一个已识别表面？同一物体在别的视角能否找到相同定义？水面和天空的编辑边界是否明确？是否有一句会诱导改变相机、扩大水域或新增窗洞？若有，先改词再生成。
